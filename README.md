# MyNotes - Asynchronous Note Management System

A sleek, full-stack web application built with **FastAPI** and **MongoDB**. This project allows users to manage their daily tasks and notes with a focus on security and real-time interaction.

## 🚀 Key Features
- **User Authentication**: Secure Login/Signup system with password hashing.
- **Email Verification**: Integrated OTP (One-Time Password) system for verifying new users via email.
- **CRUD Operations**: Full Create, Read, Update, and Delete capabilities for notes.
- **Asynchronous Performance**: Built using `Motor` for non-blocking database operations.
- **Responsive Design**: Modern UI using Bootstrap 5 and custom CSS transitions.
- **Important Notes**: You can mark the notes as important.
